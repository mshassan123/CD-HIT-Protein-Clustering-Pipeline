# CD-HIT-Protein-Clustering-Pipeline
A fully automated Google Colab pipeline for generating a non-redundant protein dataset using CD-HIT.

Features

✔ Automatic CD-HIT installation

✔ Protein FASTA upload directly in Colab

✔ Removal of proteins shorter than 100 amino acids

✔ CD-HIT clustering at 80% sequence identity

✔ Automatic paralog removal

✔ Detailed clustering statistics

✔ CSV cluster summary generation

✔ Automatic download of output files

Workflow

Input FASTA

↓

Remove sequences <100 aa

↓

CD-HIT clustering (80% identity)

↓

Remove paralogous proteins

↓

Generate non-redundant dataset

↓

Export FASTA + CLSTR + CSV

Output Files
cdhit_output_80pct

Non-redundant protein FASTA file.

cdhit_output_80pct.clstr

Cluster assignment file generated by CD-HIT.

cdhit_cluster_summary.csv

Summary of clusters and representative sequences.
